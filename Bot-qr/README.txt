5. ОПИСАНИЕ ФУНКЦИОНАЛА
----------------------------------------
Бот позволяет:
- Генерировать QR-коды из любого текста или ссылки
- Выбирать цвет QR-кода (6 готовых цветов + свой HEX)
- Выбирать формат (PNG или SVG)
- Получать адрес по отправленной геолокации
- Просматривать свой ID через команду /me

Пошаговый диалог:
1. Пользователь нажимает кнопку "Создать QR-код"
2. Вводит текст или ссылку
3. Выбирает цвет из клавиатуры
4. Выбирает формат PNG или SVG
5. Получает готовый QR-код

7. СТРУКТУРА БАЗЫ ДАННЫХ
----------------------------------------
База данных не используется. Вместо неё используются CSV-файлы и текстовые логи:

data/users.csv
Структура:
- chat_id (int) - уникальный ID пользователя в Telegram
- username (str) - username пользователя
- joined_at (str) - дата и время первого обращения

data/history/user_{chat_id}.log
Структура:
- [2026-01-15 14:30:00] USER: текст сообщения
- [2026-01-15 14:30:05] BOT: ответ бота

Связи:
- Каждый пользователь имеет один файл лога
- Связь осуществляется по chat_id

9. СПИСОК СТОРОННИХ API С ОПИСАНИЕМ
----------------------------------------
1. Telegram Bot API
   Адрес: https://api.telegram.org/bot{TOKEN}/...
   Назначение: основной API для работы с ботом (получение сообщений, отправка ответов, фото, документов, клавиатур)
   Ключ в конфиге: TELEGRAM_BOT_TOKEN (в .env файле)

2. QuickChart.io QR API
   Адрес: https://quickchart.io/qr
   Назначение: генерация QR-кодов в форматах PNG и SVG, поддержка цветных QR
   Ключ в конфиге: не требуется (бесплатный API)

3. Nominatim (OpenStreetMap)
   Адрес: https://nominatim.openstreetmap.org/reverse
   Назначение: обратное геокодирование (преобразование координат в адрес)
   Ключ в конфиге: не требуется, но требуется заголовок User-Agent

11. ТРЕБОВАНИЯ К ЗАПУСКУ
----------------------------------------
- Python версии 3.13 или выше
- Установка зависимостей: pip install -r requirements.txt
- Создать файл .env с переменными:
  TELEGRAM_BOT_TOKEN=ваш_токен_бота
  ADMIN_CHAT_ID=ваш_id_админа
- Запуск: python run.py


12. ЗАМЕЧАНИЯ ПО РАБОТЕ
----------------------------------------
- Бот использует long polling (getUpdates) с задержкой 1 секунда
- Планировщик работает в отдельном потоке
- В 08:00 МСК отправляет утреннее приветствие админу
- В 23:55 МСК отправляет отчёт о работе за день (файл .txt)
- Все сообщения пользователей сохраняются в логи
- Пользователи сохраняются в CSV без дублирования
